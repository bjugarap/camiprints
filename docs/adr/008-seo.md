# ADR 008 — SEO

**Status**: Accepted · 2026-07-26

## Context

Free coloring pages are a search-driven category; organic Google traffic is
the primary acquisition channel. The site is content-heavy and mostly
static.

## Decision

- Server Components + static generation (`generateStaticParams`) for home,
  categories, listings and detail pages.
- Next Metadata API for titles/descriptions/canonicals; filter/search state
  lives in query params with canonical URLs pointing at the unfiltered page.
- JSON-LD structured data: `CreativeWork`/`ImageObject` on detail pages,
  `BreadcrumbList` everywhere breadcrumbs render, `WebSite` + search action
  on home.
- `sitemap.xml` and `robots.txt` generated from the repository layer;
  Open Graph images per page.
- Uploaded-photo routes (`/create/photo`, admin, account) are `noindex`.

## Why

Static HTML with real content, honest titles and structured data is the
whole SEO playbook for a catalog site; nothing exotic is needed — it must
simply never regress.

## Consequences

New routes declare metadata at creation time; the sitemap generator reads
the repository, so unpublished pages can never leak into it.
